# Windows version and updates

## OS-01 · Windows version still supported
**What it is:** Each Windows 11 version (24H2, 25H2, ...) gets security updates for a fixed time: 24 months for
Home and Pro, 36 months for Enterprise and Education.
**Why it matters:** After the end date, newly found security holes are never fixed on that version.
**Recommendation:** Install the newer Windows 11 version before the end date.
**If you change it:** One download and one restart. Updates from 24H2 to 25H2 are small (an "enablement
package"). Settings and apps are kept.
**Fix:** guided.
1. Open Settings > Windows Update.
2. Install the offered "Feature update to Windows 11, version ..." (click "Check for updates" if nothing is shown).
3. Restart when asked.
**Undo:** Settings > System > Recovery > "Go back" (only for about 10 days after the update).
**Learn more:** https://learn.microsoft.com/en-us/lifecycle/products/windows-11-home-and-pro

## OS-02 · Latest security update installed
**What it is:** Microsoft releases security fixes for Windows every month (second Tuesday, "Patch Tuesday").
The check looks at when the last cumulative update was installed.
**Why it matters:** Attackers start using published security holes within days.
**Recommendation:** Install the monthly update and restart; let Windows Update run automatically.
**If you change it:** One restart. Very rarely an update causes a problem; it can be uninstalled.
**Fix:** guided.
1. Open Settings > Windows Update > "Check for updates".
2. Install everything offered, then restart.
3. If updates are paused, click "Resume updates".
**Undo:** Settings > Windows Update > Update history > Uninstall updates.
**Learn more:** https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information
